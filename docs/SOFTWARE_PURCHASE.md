## 实现与数据

- 网站 /software/checkout：套餐、支付宝/微信、二维码、订单恢复、复制兑换码、设备解绑。订单凭证只在浏览器本地保存，通过 Authorization 传递，不进入 URL。
- 软件：相同套餐和支付方式，订单保存在用户数据目录 beta/purchase.json；付款后获取原格式签名凭证，验证签名再保存；软件内解绑会先完成在途激活，再解绑并清除本地凭证。
- 已付款且未到期的同套餐购买复用原订单；年费到期后新建续购请求，永久授权不重复收费。购买码可复制保存，解绑后不会在旧设备自动恢复激活。
- 付费订单新增 software_beta_purchases 表；软件码使用独立付费批次，不占用学员 1000 码库存，也不影响星光账本。
- 简付模块来自 aicollection 项目：签名下单、查询、回调验签。金额和期限由服务器决定；只有已确认支付的订单发码。重复请求复用订单，回调/查询共用幂等结算。网络或响应未知时不自动创建第二笔支付单。
- 免费 MP4 在实时与写实编码两路直接叠加动态品牌 PNG；图片/透明 MOV/PNG 序列仍校验签名授权。客户端不能取消免费任务的水印。
- 本轮迁移仅新增表/索引，保留原产品、码、星光、课程、VOD 和用户数据。库存导入仍对学员码单独限制 1000。

## 运维与配置

软件购买开关 SOFTWARE_PAYMENT_ENABLED 独立于 NEXT_PUBLIC_PAYMENT_SYSTEM_ENABLED；原课程支付开关仍保持 false。正式商户信息只使用服务器 JIANPAY_CLIENT_NO/JIANPAY_KEY，网关使用 HTTPS。软件不包含商户密钥。

上线顺序：备份网站数据库和配置 -> 运行幂等迁移 -> 部署网站 1.15.0 -> 配置/确认既有简付商户及软件回调 https://ai3dclass.cn/api/software-beta/payment/notify -> 受控验收后启用软件购买 -> 发布新的软件固定版本与外部校验清单。不得覆盖旧固定 Release。

尚未进行真实扣款或生产回调验收；本地支付预览均为假网关和合成数据库、密钥。当前没有用户自助退款。运营人员若在简付后台退款，必须同时停用本系统对应软件码，并记录退款/停码结果。已签发的离线凭证无法由网页远程清除，正常换机应在原软件内解绑；永久离线不是严格的单设备在线租约。
