# 快速开始

## 1. 安装并启动

本轮固定版本为 [v1.2.0-beta.2](https://github.com/dashan914/growth-timelapse-studio/releases/tag/v1.2.0-beta.2)，待发行；发行资产验证后，自动安装使用同版本的 [外部安装清单](https://github.com/dashan914/growth-timelapse-studio/releases/download/v1.2.0-beta.2/install-manifest.json)。上一版 1.2.0-beta.1 已公开预发布。

准备 Node.js 24 LTS（最低 22）、Python 3，以及 Bambu Studio、OrcaSlicer 或 Flash Studio 中的一种切片器。导出 MP4 / MOV 还需要 FFmpeg。

在项目目录打开终端：

```sh
npm ci
npm run doctor
npm start
```

`doctor` 检查本机依赖。打开终端显示的地址，默认 `http://127.0.0.1:4317`。macOS 首次安装后也可双击 `start.command`，或执行 `bash start.command`。

也可把 [Agent 安装指南](../INSTALL_AGENT.md) 的链接交给能操作本机终端的 Agent，自动完成环境检查和安装。

安装后直接进入工作台，导入、编辑和预览免费开放。免费用户选择 MP4 后，可以点击“免费导出 · 带动态水印”；无水印视频、预览图片、透明 MOV 和 PNG 序列需要解锁。

点击“导出解锁”，选择一年 ¥19.90（365 天）或永久 ¥39.90，用支付宝或微信扫码支付，软件确认后自动激活。也可到 [山地造物购买页](https://ai3dclass.cn/software/checkout) 购买，复制兑换码回软件输入。购买授权绑定一台设备，换机前先在旧设备解除绑定并保留兑换码。首次解锁需联网；成功后可在有效期内使用本机签名凭证离线导出。

“山地造物学员”入口仍跳转 [原星光兑换页面](https://ai3dclass.cn/points)，沿用原学员资格、星光消耗和学员码设备规则。已有兑换码继续有效。

扫码时学员入口仍保留；未付款可返回套餐选择，切换一年（YEAR）或永久（LIFETIME）。原二维码在有效期内仍可付款，请不要两笔都支付。原订单凭证保存在本机，付款结果不确定时先查询原订单。

## 2. 导入模型

点击“导入模型”，选择 [测试2.3mf](../examples/测试2.3mf)，或自己的 STL / 含原模型网格的单盘 3MF，等待本机切片完成。

3MF 可读取工程内的涂色和对象设置；STL 使用界面设定的颜色。多盘工程请先在切片软件中整理为单盘。加载时可点击“取消导入”或“取消切片”。

## 3. 选择背景与摆放

1. 在“选择背景预设”中选择 H2C、P1S、A1、彩绒台面、蓝灰棚或青绿室内，自动应用对应构图。
2. 点击预览下方“移动”“旋转”“缩放”，拖动手柄调整模型；点击“锁定”或按 Esc 结束。
3. 点击“透视”“光影”“景深”，调整机位、投影和模型虚化；在右侧选择原色或表面质感。
4. 点击播放，或拖动时间线查看生长过程。

自己的照片点击“自定义导入图片背景”。照片可用“调整底板，矫正透视”或“微调台面”标记四角与实际尺寸，再用照片中的竖直立柱校正方向；“自动找立柱”得到的候选需要确认。如需用成品照片对照模型，可点击“导入成品照片辅助对齐（可选）”。固定机位视频使用实时画质。

## 4. 设置并导出

可先设置“生长用时”为 3 秒，展开“动画设置”把“完成停留 / 秒”设为 1，选择 720p 和“实时 · 快速生成”。总时长为生长用时加完成停留。

| 格式 | 用途 | 依赖与权限 |
| --- | --- | --- |
| MP4 · 带背景视频 | 包含背景与底面投影，直接播放或分享 | FFmpeg；免费动态水印，解锁后无水印 |
| MOV · 透明通道视频 | 在剪辑软件中叠加模型 | 支持 ProRes 4444 的 FFmpeg；需解锁 |
| PNG · 透明图片序列 | 逐帧后期合成，打包为 ZIP | 无需 FFmpeg；需解锁 |

透明输出保留模型与透明边缘，去除背景和底面投影。点击右上角“导出视频”，保持页面和启动终端打开；完成后点击下载，文件也保存在 `exports/`。结束使用时在启动终端按 `Ctrl+C`。

免费 MP4 的动态水印采用较小、较淡的品牌标识，在画面中部缓慢双轴移动。预览中可先查看水印样式，再决定免费导出或解锁无水印。

## 5. 可选功能与排查

| 场景 | 操作 |
| --- | --- |
| 使用写实画质 | 安装 Blender 4.5 LTS，重启服务；使用静态照片、关闭完整支撑，再选择“写实 · 自然光影”。静止后生成当前帧预览，导出时逐帧渲染。 |
| 使用自动找立柱 | 在 Python 环境安装 `opencv-python-headless` 与 `numpy`；也可直接手动标记。 |
| 未检测到切片器 | 确认切片软件已安装；自定义位置设置对应程序路径，见 [开发说明](DEVELOPMENT.md)。 |
| MP4 / MOV 无法导出 | 运行 `npm run doctor` 检查 FFmpeg；必要时设置 `FFMPEG_PATH` 后重启。已解锁用户也可先用 PNG 序列。 |
| 购买或首次激活暂时无法联网 | 可以继续编辑、预览或导出带动态水印的 MP4；已验证的有效凭证仍支持离线导出。 |
| 扫码后想改套餐或改用学员兑换 | 未付款先返回套餐选择，或使用仍保留的学员入口；原订单凭证本地存档，原二维码在有效期内仍有效，只支付最终选择的一笔。 |
| 需要更换购买授权的电脑 | 在旧设备的“导出解锁”窗口点击“解除当前设备绑定”，复制购买兑换码后在新设备激活。 |
| 恢复上次项目 | 使用相同浏览器和本机地址；恢复时会重新切片。浏览器素材缓存与设置可随清除浏览器数据一起删除。 |

反馈问题时附上系统与依赖版本、文件类型、操作步骤和错误截图。逐个按钮的图文说明见 [界面操作指南](UI_GUIDE.md)。
