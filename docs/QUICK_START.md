# 快速开始

## 1. 准备本机环境

安装 Node.js 24 LTS（最低 22）、Python 3，以及 Bambu Studio、OrcaSlicer 或 Flash Studio 中至少一种切片器。MP4 / MOV 导出还需要 FFmpeg。

macOS Apple Silicon 已验证。Windows / Linux 请先运行检测，再用一个简单模型检查导入、切片和导出；当前尚无完整跨平台验证。

在项目目录打开终端，执行：

```sh
npm ci
npm run doctor
npm start
```

`doctor` 显示本机依赖是否可用，不会安装外部软件。若缺少 Blender 或 OpenCV，可以先使用实时画质与手动校准。打开终端显示的地址，默认 `http://127.0.0.1:4317`。

macOS 首次安装完成后可双击 `start.command`。如果无法双击运行，在终端执行 `bash start.command`，或继续使用 `npm start`。

## 2. 导入自己的模型

选择附带的多色案例 [测试2.3mf](../examples/测试2.3mf)，或自己的 STL / 含原模型网格的单盘 3MF。软件自动查找本机切片器，并重新计算打印路径；导入过程中原文件只读。附带案例由用户指定，模型保留独立许可，见 [案例说明](../examples/README.md)。

3MF 的原色与对象设置会在可支持的范围内保留。STL 不包含耗材颜色，按界面设置显示。多盘、无原模型网格或不兼容的文件会提示失败；需要回到建模或切片软件整理后重新导入。

先用一个简单模型确认流程。较大模型可能需要更长的切片与加载时间；可以取消本次操作，失败时再重试。

## 3. 选择背景与摆放

点击内置背景，软件应用对应的默认机位和模型摆放。用移动、旋转、缩放工具调整模型；默认锁定状态下拖动画面不改变机位。

使用自己的照片时，通过“微调底板”或“微调台面”标记平面四角、确认尺寸，再用真实竖直立柱校正方向。标注质量影响透视；“自动找立柱”给出的是候选线，需要人工确认。

还可导入固定机位背景视频，使用实时画质制作。移动机位和前景物体对模型的自动遮挡尚未支持。

调整模型的光影、颜色、材质和景深，使其接近背景。单张照片无法直接还原完整真实光照，必要时手动微调。

## 4. 导出第一条视频

先选“实时 · 快速生成”、短生长时间和较低分辨率进行试导出，再按需要提高分辨率。总时长为生长用时加完成停留，完成停留默认 0 秒。

| 格式 | 适用情况 | 依赖 |
| --- | --- | --- |
| MP4 | 成片直接发布，包含背景与底面投影 | FFmpeg |
| MOV 透明通道 | 在剪辑软件叠加模型，文件较大 | 支持透明 ProRes 4444 的 FFmpeg |
| PNG 透明图片序列 ZIP | 后续合成，或没有视频编码器时 | 不需要 FFmpeg |

透明导出保留模型与透明边缘，移除背景和底面投影。需要照片上的投影时选 MP4。

导出期间保持页面和启动终端打开。完成后可以下载，也能在项目 `exports/` 目录找到文件。结束使用时在启动终端按 `Ctrl+C`；关闭启动终端也会结束服务。

## 5. 可选功能与排查

**写实画质：**安装 Blender 4.5 LTS，必要时设置 `BLENDER_PATH`，重启并运行 `npm run doctor`。使用静态照片，关闭完整历史支撑后选择“写实 · 自然光影”。静止后会计算当前帧的写实预览，视频会逐帧计算，速度取决于设备和模型。

**自动竖线建议：**在 Python 环境安装 `opencv-python-headless` 与 `numpy`，再重启服务。可以用 `PHOTO_CALIBRATION_PYTHON` 指定单独的 Python 环境。功能缺失时直接手动标记即可。

**未检测到切片器：**确认切片软件可正常启动；自定义安装位置时指定 `BAMBU_STUDIO_PATH`、`ORCA_SLICER_PATH` 或 `FLASH_STUDIO_PATH`。变量值应是程序可执行文件，macOS `.app` 内的可执行文件位置见 [开发说明](DEVELOPMENT.md)。

**无法导出 MP4 / MOV：**运行 `npm run doctor` 检查 FFmpeg。可通过 `FFMPEG_PATH` 指定编码器，再重启。透明 MOV 还要求编码器支持；可先导出 PNG 序列。

**恢复上次项目失败：**使用原浏览器和相同本机地址，确认原模型与本机切片器仍可用；恢复流程需要重新切片。清除浏览器数据会删除其项目缓存。

**报错反馈：**记录系统、依赖版本、文件类型和复现步骤；分享截图与经过检查的错误信息。若提交模型或照片，先确认它们可以公开分享。
