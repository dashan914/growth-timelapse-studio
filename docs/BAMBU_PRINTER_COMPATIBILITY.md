## 修复内容

- 支持 P2S 等型号在模型打印前的 G130 预挤出宏；不猜测宏的最终位置，后续必须明确定位。绝对挤出还必须重置 E 坐标。
- 补充 A1/A1 mini/X2D 的 G2814、G29.4、G39、G39.3、G39.4、G383.4 机器动作，保留位置不确定性检查。
- 正确解析 A2L G390.7 的 M/G 参数，避免将参数 G6 当成独立样条运动。
- 模型阶段不支持的真实运动继续报错，无法重建的辅助预挤出不会被伪造为模型墙线。

## 可重复执行

运行 scripts/test-bambu-printers.py，显式传入 --resources、--slicer、--output（独立临时目录），再运行 node scripts/check-bambu-printer-results.mjs <同一输出目录>。

本报告验证的是小模型的本机切片与数据解析，未对所有机型执行实体打印，也未在 Windows 上重新进行实机验收。复杂多色、多盘、所有材料及实际打印质量不由本次矩阵覆盖。现有模型/涂色/支撑/安装/激活测试另行验证。

激活校验代码与 beta-config.json 保持不变。GitHub 已发布下载包没有被本次本地整合替换。
