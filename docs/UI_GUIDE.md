# 界面操作指南

按“导入模型 → 选择背景 → 调整摆放与光影 → 预览 → 导出”完成一条视频。

![工作台六个操作区](media/ui-overview.jpg)

| 编号 | 操作区 | 用途 |
| --- | --- | --- |
| 1 | 导入模型 | 选择 3MF / STL，查看切片进度与支撑 |
| 2 | 背景 | 导入照片或视频，切换内置场景 |
| 3 | 工具栏 | 移动、旋转、缩放、透视、光影、景深 |
| 4 | 时间线 | 播放、从头播放、拖动进度、循环 |
| 5 | 输出 | 设置时长、比例、分辨率、材质与格式 |
| 6 | 导出 | 生成视频并下载 |

## 1. 导入模型与选择背景

点击“导入模型”，选择 [测试2.3mf](../examples/测试2.3mf)，或含原模型网格的单盘 3MF / STL。等待本机切片完成；“显示支撑”控制支撑是否出现在画面中。

选择 H2C、P1S、A1、彩绒台面、蓝灰棚或青绿室内，应用对应的机位、摆放和光影。切换背景后先检查构图，再继续微调。自己的素材用“导入照片 / 视频”，固定机位视频选择实时画质。

![A1、蓝灰棚和彩绒台面的背景切换](media/ui-backgrounds.gif)

## 2. 调整摆放与预览

![模型摆放工具](media/ui-placement.jpg)

点击“移动”“旋转”或“缩放”，拖动模型手柄调整；快捷键为 W / E / R。点击“锁定”或按 Esc 结束，右上角回正图标恢复背景预设的构图。

底部“透视”可调俯视角、左右视角、镜头焦段与倾斜。顶部“透视 / 正面 / 侧面 / 俯视”用于切换观察方向。

播放按钮预览生长过程；从头播放按钮重新开始，拖动时间线可检查任一阶段，勾选“循环”反复观看。重点看模型位置、底部落点和完整模型是否都在画面内。

![切换移动、旋转、缩放与锁定，检查时间线0%、50%与100%](media/ui-tools-preview.gif)

## 3. 对齐底板透视

![底板四角与尺寸设置](media/ui-calibration.jpg)

1. 选择照片背景，点击“微调底板”；摄影背景对应“微调台面”。
2. 在“1 · 底板四角”选择“平面参考尺寸”，或填写“宽 / mm”“深 / mm”。所标矩形须对应这个实际尺寸，钢板外缘与可打印区域可能不同。
3. 按编号把蓝点贴住四角：1 后左、2 后右、3 前右、4 前左。蓝色虚框是标记，实线网格显示模型相机的实际投影；核对边缘方向与模型底部落点。
4. 用“微调点”选择角点或竖线端点，再点箭头按钮微调；选中画面端点后也可按方向键，按住 Shift 加速。

![校正竖直参考线](media/ui-uprights.jpg)

5. 切到“2 · 校正竖直”，把两条绿线的端点贴住照片中的真实竖直立柱。绿线跟随照片里的立柱方向，无需拉成屏幕竖线。“自动找立柱”可提供候选，核对后再调整。
6. 确认后勾选“使用已贴住立柱的参考线”。若模型本身有俯仰或侧倾，可点“模型站直”，保留位置、朝向与大小。
7. 检查网格和模型方向，点击“完成”保存。想回到本次进入时的标记可点“重置标记”；“取消”返回调整前的场景。

动图以 A1 为例：设置自定义尺寸 256 × 256 mm，微调角点，再进入“校正竖直”，点击“模型站直”并完成。

![尺寸设置、角点微调与校正竖直](media/ui-calibration.gif)

## 4. 调整模型光影

![光影与颜色参数](media/ui-lighting.jpg)

点击工具栏“光影”，先根据背景确定光源方向，再调整投影和模型颜色。

| 控件 | 调整时看什么 |
| --- | --- |
| 显示阴影、强度、柔和度 | 底部投影的深浅与边缘，确认模型与台面接触自然 |
| 方向、左右旋转、上下角度 | 投影朝向和长度，与背景中已有阴影相近 |
| 模型亮度 | 模型整体亮度，与周围物体协调 |
| 色温、色调 | 冷暖与偏色，跟随背景环境 |
| 暗部亮度、高光亮度 | 阴影细节与亮面，保留形体层次 |
| 对比度、饱和度 | 明暗差和颜色浓度，逐项小幅调整 |

![完整的底面投影参数](media/ui-shadow.jpg)

展开“颜色与光线”使用颜色参数；“恢复预设光影”重新应用当前背景的光影与景深。右侧“模型原色”保留模型配色，“统一颜色”改成单色，“表面质感”切换 PLA、哑光、丝绸等效果。

需要虚化时点击“景深”，勾选“启用虚化”，调整强度和焦点位置。完成后关闭面板，分别查看完整模型和生长中段。

动图演示模型亮度从 95% 调到 110%，色温从 6500 K 调到 5300 K，再调整阴影强度、柔和度及左右方向，最后恢复预设光影。

![亮度、色温与底面投影调节](media/ui-lighting.gif)

## 5. 设置输出并导出

![输出参数与导出入口](media/ui-output.jpg)

右侧设置“生长用时”、比例、分辨率和渲染画质；展开“动画设置”修改“完成停留 / 秒”和帧率。总时长为生长用时加完成停留。示例使用 3 秒生长、1 秒停留、720p、24 fps。

| 格式 | 输出内容 |
| --- | --- |
| MP4 · 带背景视频 | 背景、模型与底面投影 |
| MOV · 透明通道视频 | 透明模型视频，用于后期叠加 |
| PNG · 透明图片序列 | 透明逐帧图片，打包为 ZIP |

MP4 / MOV 需要 FFmpeg。写实画质需 Blender、静态照片，并关闭完整支撑；首次可选“实时 · 快速生成”。

点击右上角“导出视频”，保持页面与启动终端打开。完成后点击下载，文件也保存在 `exports/`。

![设置与导出操作](media/ui-export.gif)

成片效果见 [案例 GIF](media/demo-model.gif) 与 [清晰 MP4](media/demo-model.mp4)。环境安装见 [快速开始](QUICK_START.md)。
