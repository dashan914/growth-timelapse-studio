# 界面操作指南

本指南对应固定版本 [v1.2.0-beta.7](https://github.com/dashan914/growth-timelapse-studio/releases/tag/v1.2.0-beta.7)，官方安装文件为 `growth-timelapse-studio-1.2.0-beta.7-runtime.zip`。

制作流程：**导入模型 → 选择背景 → 调整摆放和画面 → 预览 → 导出**。

## 1. 工作台与导入

![当前工作台与模型预览](media/current-workbench.gif)

点击“导入模型”，选择 [测试2.3mf](../examples/测试2.3mf)，或含模型网格的单盘 3MF / STL，等待本机切片完成。多色工程保留涂色分区；“显示支撑”控制预览中的支撑。

工作台实时预览始终无水印。时间线可播放、循环或拖动进度，检查模型在不同层高的状态。关闭弹窗或按 Esc 会保留当前模型和设置。

### 显示与隐藏支撑

![显示与隐藏工程中的真实切片支撑](media/current-supports.gif)

1. 在切片软件中启用支撑，确认切片预览确实包含支撑，保存含原模型网格的单盘 3MF 工程。
2. 导入工程并等待切片完成；左侧“显示支撑”可勾选时，勾选查看支撑，取消勾选只看模型。
3. 拖动时间线到中段和完成位置，检查支撑与模型在不同层高的状态。

开关只控制已有支撑的显示，不会生成支撑。工程的实际切片没有支撑时开关不可用，3MF 会提示“此切片未包含支撑”；此时先检查切片工程设置，再保存并重新导入。

## 2. 背景与透视对齐

![当前背景预设切换](media/current-backgrounds.gif)

在“或直接使用背景预设”中选择 H2C、P1S、A1 或摄影场景，自动应用对应构图。自己的照片使用“自定义导入图片背景”；固定机位视频使用实时画质。

![H2C 背景的底板实际尺寸、四角与竖直方向校正](media/current-bed-calibration.gif)

动图演示 H2C 背景，参考矩形为 330 × 320 mm；实际照片按所标矩形的真实尺寸和可见角点对齐。

照片对齐：

1. 选择照片背景并点击“调整底板，矫正透视”。在“平面参考尺寸”选择 H2C · 330 × 320 mm、P1S / A1 · 256 × 256 mm，或选择“自定义尺寸”填写实际宽、深。标记矩形须对应所填尺寸，整张钢板外缘未必等于可打印区域。
2. 在“1 · 底板四角”把四个蓝点按 **1 后左、2 后右、3 前右、4 前左** 贴住相应角点。蓝色虚框是手动标记，实线网格显示实际相机投影。
3. 在“微调点”选角点，再用箭头按钮精调；画面端点获得键盘焦点后，也可用方向键微调，Shift 加速。照片中看不到的角只能估计。
4. 切到“2 · 校正竖直”，将绿线两端贴住照片中确定竖直的立柱或导轨，按照片里的方向贴线，不能简单拉成屏幕竖线。“自动找立柱”提供的候选也须核对。
5. 勾选“使用已贴住立柱的参考线”，检查实线网格方向与模型底部落点；若模型有俯仰或侧倾，可使用“模型站直”。点击“完成”保存，“取消”返回调整前的场景。

“导入成品照片辅助对齐（可选）”可用成品照片对照模型；没有成品照片也可完成透视调整。

## 3. 模型摆放

![当前模型真实移动与缩放](media/current-transform.gif)

- 点击“移动”（W），拖动轴向手柄调整位置。
- 点击“旋转”（E），拖动圆环改变朝向。
- 点击“缩放”（R），拖动手柄调整大小。
- 点击“锁定”或按 Esc 结束调整；回正按钮恢复预设构图。

顶部“透视 / 正面 / 侧面 / 俯视”切换观察方向。镜头焦段在“镜头设置”中调整。

## 4. 色彩、阴影与镜头

![当前色彩匹配和镜头设置](media/current-color-lens.gif)

| 入口 | 设置 | 调整目的 |
| --- | --- | --- |
| 阴影调节 | 方向、强度、柔和度 | 匹配背景的光源与底面投影 |
| 色彩匹配 | 亮度、色温、色调、暗部、高光、对比度、饱和度 | 让模型颜色与背景协调 |
| 镜头设置 | 焦段滑条和数值、虚化强度、焦点 | 调整镜头与模型近远虚化 |
| 运镜与音效 | 推进幅度、推进用时、默认音效、自定义音效导入 | 让画面随时间推进并同步播放音效 |

“色彩匹配”的独立恢复只恢复色彩参数。“镜头设置”同时提供焦段和虚化；需要虚化时勾选“启用虚化”，再调整强度与焦点。照片保留实拍景深。

### 镜头推进与音效

点击“镜头设置”旁的“运镜与音效”，将镜头运镜设为“平滑推进”。“推进幅度”是最终放大的百分比，20% 对应最终 1.2 倍；“推进用时 / 秒”越短，推进越快。推进默认匀速，结束后保持最后构图。画面整体从中心放大和裁切，模型与照片背景保持对齐。

勾选“使用默认音效”后，播放预览即可听到随软件提供的参考原声。需要自己的音效时，导入音效文件，单文件不超过 50 MiB；导入会自动取消默认音效，预览和视频导出改用该文件。

| 音效状态 | 预览与视频导出 |
| --- | --- |
| 勾选“使用默认音效” | 使用参考原声，并清除此前导入的自定义文件 |
| 未勾选，已导入自定义文件 | 使用自定义音效 |
| 未勾选，没有自定义文件 | 静音 |

移除自定义文件后保持静音。音效随播放、暂停、重新开始和拖动时间线同步，只播放一次，较长视频后段保持静音。MP4 和透明 MOV 包含选中的音效；PNG 序列不含声音。直接播放预览检查效果，无需单独试听或设置音效播放位置。

开启推进或音效时使用实时画质；关闭推进、取消默认音效并移除自定义文件后可选择写实画质。

### 更改模型颜色

![耗材分区换色与统一颜色切换](media/current-model-colors.gif)

1. 导入多色 3MF 并等待切片完成，在右侧“材质”勾选“模型原色”。有耗材分区时会显示“耗材 N”的颜色列表。
2. 点击要修改的耗材色块并选择颜色，该耗材对应区域一起换色；此操作会自动启用“模型原色”，保留分区显示。
3. 想让整个模型同色时，点击“统一颜色”色块选择颜色，程序会自动取消“模型原色”。
4. 重新勾选“模型原色”切回耗材分区显示，之前修改的耗材颜色仍保留；这不会重新载入工程默认色。单色模型可直接使用“统一颜色”。

表面质感可选择 PLA、哑光、丝绸或 PETG，比较高光与粗糙度。“层纹”开关和“细节强度”也在右侧“材质”区域，调整打印表面的层线与细节。耗材分区换色与“色彩匹配”的整体亮度、色温等参数可以分别调整。

## 5. 设置输出

设置生长用时、完成停留、比例、分辨率和画质，总时长为生长用时加完成停留。首次可选择 3 秒生长、1 秒停留、720p 和“实时 · 快速生成”。

| 格式 | 输出内容 |
| --- | --- |
| MP4 | 带背景、模型与投影的视频 |
| MOV · ProRes 4444 | 透明模型视频，用于剪辑合成 |
| PNG 序列 ZIP | 透明逐帧图片，用于后期合成 |

点击“导出视频”，保持页面与服务运行；完成后下载文件。MP4 / MOV 需要 FFmpeg，写实画质还需 Blender、静态照片并关闭完整支撑。

只有免费 MP4 成片写入动态品牌水印，工作台实时预览不叠加水印；已解锁的成片无水印。无水印视频、预览图片、透明 MOV 和 PNG 序列需要解锁。原学员星光兑换、购买和已有兑换码流程继续使用；价格为一年 ¥19.90（365 天）或永久 ¥39.90，购买授权绑定一台设备，换机前先解绑。

成片示例见 [清晰 MP4](media/demo-model.mp4)，环境准备见 [快速开始](QUICK_START.md)。安装 AI 可使用 [完整安装提示词](../INSTALL_AGENT.md)。

已有安装使用 [Agent 升级指令](../INSTALL_AGENT.md#老用户升级)，保留原安装目录、授权、订单和作品。有效年付授权的到期时间不变，永久授权继续有效；目前没有软件内自动更新。
