## 发布短文草稿

我把“打印延时一键生成”整理成了免费开源工具。

导入自己的 STL 或单盘 3MF，本机切片后就能制作从底部逐层生长的动画。支持多色、实际填充与支撑，也能叠加照片背景，或导出透明素材放进剪辑软件。

这是模型模拟动画，不是打印机拍摄录像。默认实时画质，安装 Blender 后还可尝试写实渲染；写实效果与速度取决于模型、背景和设备。

当前验证了 macOS Apple Silicon，首次使用需要自行安装运行依赖。欢迎试用、反馈，也欢迎分享你做出的成片。

发布时在这里附上真实仓库地址、下载入口和操作教程。
